Визуализатор сортировок (ASD_Project_2026) 

Веб-приложение на базе **Python (Flask)** и **HTML/JS**, которое позволяет вводить массив чисел и сортировать его различными алгоритмами прямо в браузере. 

В проекте реализованы следующие алгоритмы:
1. Сортировка бусинами (Beadsort)
2. Гномья сортировка (Gnome Sort)
3. Пирамидальная сортировка (Heapsort)
4. Случайная сортировка (Bogosort)
5. Сортировка сном (Sleep Sort)

Инструкция по установке и запуску

Для запуска проекта вам понадобится установленный **Python** (версия 3.8 или выше) и **Git**.

Шаг 1. Клонирование репозитория
Скачайте проект на свой компьютер и перейдите в папку с ним:

git clone https://github.com/DwinFi/ASD_Project_2026.git
cd ASD_Project_2026
Шаг 2. Создание виртуального окружения (venv)
Виртуальное окружение нужно, чтобы библиотеки проекта не конфликтовали с другими программами на вашем компьютере.

Для Windows:

bash
python -m venv .venv
.venv\Scripts\activate
Для macOS / Linux:

bash
python3 -m venv .venv
source .venv/bin/activate
(После активации в начале строки терминала появится (.venv)).

Шаг 3. Установка зависимостей (Flask)
В активированном виртуальном окружении установите веб-сервер Flask (библиотеку, которая запускает сервер):

bash
python -m pip install flask
Шаг 4. Запуск сервера
Перейдите в папку с исходным кодом сайта и запустите сервер:

bash
cd sort_website
python app.py
Шаг 5. Открытие сайта
После запуска в терминале появится строка:
Running on http://127.0.0.1:5000
Зажмите клавишу Ctrl и кликните по этой ссылке (или скопируйте её и вставьте в адресную строку браузера).
